О проекте

Я создала игру-платформер на языке Python с использованием библиотеки Pygame. В игре есть персонаж, платформы, монетки и финишный флаг.

Цель игры — собрать все монетки и добраться до финиша, прыгая по платформам. Игра демонстрирует навыки программирования: работу с физикой, коллизиями, циклами и классами.

Скриншоты игры

Как запустить игру

  1. Установить Python с сайта python.org
  2. Установить библиотеку Pygame командой pip install pygame
  3. Сохранить файл platformer.py и запустить его
  4. Играть с помощью клавиш W, A, S, D

def create_level():
    platforms = [
        pygame.Rect(0, HEIGHT - 40, WIDTH, 40),  # земля
        pygame.Rect(50, 450, 150, 20),
        pygame.Rect(200, 350, 150, 20),
        pygame.Rect(550, 250, 150, 20),
    ]
    coins = [Coin(100, 400), Coin(250, 300)]
    finish = Finish(720, 0)
    return platforms, coins, finish
